## What I built

- A framework that combines Prolog-based knowledge graphs with LLM inference pipelines, using symbolic knowledge to improve factual grounding and consistency on multi-step reasoning tasks.
- Distributed GPU training and inference workflows on Kubernetes, Docker, and cloud-native infrastructure, so model configurations could run as parallel experiments.
- Modular evaluation pipelines in PyTorch and Hugging Face Transformers that compare open-source LLMs on structured reasoning and factual consistency.
