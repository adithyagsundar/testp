## Hearth

A household assistant inside a Telegram group chat. It turns messages and receipt photos into expense splits, grocery lists, reminders, and maintenance tasks, using shared household context to coordinate follow-up actions.

A tool-calling runtime connects persistent state, browser automation, and vendor calls. Purchases and bill payments pause for approval; demo mode simulates external actions.

**First place, Agent Native Hackathon.** Built with TypeScript, Node.js, Nebius, Butterbase, Browserbase/Stagehand, and Vapi.

[Explore Hearth on GitHub](https://github.com/Ansh-Karnwal/Hearth)

## Fixate

An AI tool for reviewing landing pages and campaign images before spending on traffic. Submit a URL, HTML, or image to get attention analysis, likely conversion blockers, creative variants, and an A/B test plan.

A React interface streams progress from a FastAPI pipeline that combines Playwright captures with OpenAI vision and generation. Optional Convex integration persists analysis history. Results are model-generated hypotheses to test, rather than measured customer behavior.

[Explore Fixate on GitHub](https://github.com/Ansh-Karnwal/Fixate)
